# DefiQuad

Turns cryptocurrency swap rates and liquidity pool data into easy-to-read dashboards for decentralized finance (DeFi) professionals and researchers.

The key benefits of using DefiQuad include:

- Turns cryptocurrency swap rates and
- liquidity pool data into easy-to-read
- dashboards for decentralized finance (DeFi)

- javascript

- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiQuad.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
